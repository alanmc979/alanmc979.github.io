<details>
<summary>Development and deployment</summary>

Use Node.js 22.12 or newer:

```sh
npm install
npm run dev
```

Open http://127.0.0.1:5173. For a production build, run `npm run build`, then
`npm run preview` to preview it locally. Commit the generated `package-lock.json`
for reproducible installs.

Content lives in `src/main.jsx`, styles in `src/styles.css`, and photos in
`public/photos`. Add descriptive alternative text and remove location metadata
when adding photos.

The workflow in `.github/workflows/pages.yml` builds and deploys to GitHub Pages
on pushes to `main` or manual runs. Set **Settings > Pages > Source** to
**GitHub Actions**. Deployment requires both jobs to complete successfully.

</details>
